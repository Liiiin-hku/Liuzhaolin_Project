# Dual-Sensor Workflow Compatibility Note

This former page is retained only so older links remain valid. The maintained workflow
is divided across:

- [Sensor configuration](02_SENSOR_CONFIGURATION.md)
- [Camera calibration](03_CAMERA_CALIBRATION.md)
- [Sensor and depth calibration](04_SENSOR_CALIBRATION.md)
- [Shape reconstruction](05_SHAPE_RECONSTRUCTION.md)
- [Data collection](07_DATA_COLLECTION.md)
- [Model training](09_MODEL_TRAINING.md)

calibration paths, datasets, and model paths must remain isolated.
