# Reference Library Index

This library is the indexed companion to the 33 references cited in the final dissertation. Metadata was checked against DOI/OpenAlex records or the cited official source. Public files were obtained only from publisher pages, author or institutional repositories, arXiv, the official Robotiq site, or the official 9DTact GitHub repository. No paywall or access control was bypassed.

## Coverage

- Dissertation bibliography records: **33**
- Publicly available PDFs downloaded and parsed: **20** (144,631,561 bytes)
- Official non-PDF source records archived: **1** (9DTact repository README and license)
- Link-only records after public-source checks: **12**
- Detailed per-reference provenance: `REFERENCE_DOWNLOAD_MANIFEST.csv`
- Thesis-use mapping and current local path: `../LITERATURE_INDEX.csv`

## Directory

- `Files/` — legally/publicly accessible reference files that passed format/readability checks.
- `REFERENCE_DOWNLOAD_MANIFEST.csv` — reference number, verified metadata, DOI/official URL, access status, download source, size, SHA-256, and readability.
- `COPYRIGHT_AND_ACCESS.md` — reuse and unavailable-item boundaries.

## Use

- All 33 dissertation references are indexed in `../LITERATURE_INDEX.csv`.
- Publicly available local copies are provided for convenient reading; DOI and official URLs remain the citation authority.
- The official 9DTact README/LICENSE records document the referenced open-source project.
- Reuse remains subject to each source's copyright and license terms.
