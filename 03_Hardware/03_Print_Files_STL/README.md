# STL Print Files

Seven custom sensor, calibration and FT300 connection parts are paired with their native SolidWorks sources under `03_Hardware/01_CAD_Source/SolidWorks_Parts/`. Two gripper STL files remain under `Existing_Source/Gripper/`.

`STL_SOURCE_MAPPING.csv` records both file hashes, triangle counts and mesh checks. The seven imported files pass binary-length, finite-value, non-degenerate, single-component and closed 2-manifold checks. STL files do not encode units, so unit scale, fit, tolerances and printer settings must be confirmed against the native CAD and physical assembly before fabrication.
