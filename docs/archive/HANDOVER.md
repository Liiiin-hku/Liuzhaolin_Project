# 技术交接摘录

[返回首页](../../README.md) · [软件复现](../../02_Software/SOFTWARE_INDEX.md)

此文从原教师交接说明中保留技术操作顺序，作为维护参考。作品集首页和验证状态是当前展示入口。

1. 阅读 [项目概览](../PROJECT_OVERVIEW.md)、[验证边界](../VALIDATION_STATUS.md) 与 [版本冻结](../../VERSION_FREEZE.md)。
2. 按冻结快照的 Ubuntu 安装文档准备环境，先做静态检查。
3. 选择一个传感器，确认相机编号、图像和配置；Sensor 1/2 数据、归一化文件和模型应各自隔离。
4. 硬件运行前核实实际接线、极性与电源条件；当前缺完整核准的接线图。
5. 相机和深度标定会写入数组，仅在明确需要重新标定并保存原文件后执行。当前共享数组与上游深度 LUT 的限制见验证说明。
6. FT300 驱动需先提供 `geometry_msgs/WrenchStamped`；核实 topic、frame、轴方向、时间戳和无载状态后再启动采集。
7. 对同步图像、混合图像和 wrench 三元组做完整性检查；正式训练还需要规范数据集、物体隔离划分、归一化元数据和独立测试。

FT300 是采集标签及比较参考，触觉模型的正常预测输入是图像。归一化输出不可标作 N 或 N·m。定性视频和离线测试均不能替代完整硬件与精度验收。
