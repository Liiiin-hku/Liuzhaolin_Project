# Project Demonstrations

This directory contains three qualitative demonstrations of the completed tactile-sensor project. `VIDEO_SOURCE_MAPPING.csv` records duration, resolution, codec, size, and SHA-256 for each video.

| File | Demonstrated work |
|---|---|
| `Successful/custom_tactile_sensor_hardware_showcase.mp4` | Completed custom tactile-sensor hardware, illumination, USB connection, and Ubuntu interface |
| `Successful/shape_reconstruction_pressing_demo.mp4` | Physical pressing of the tactile sensor with a corresponding changing contact/shape visualization |
| `Successful/realtime_6d_force_visualization_demo.mp4` | Physical sensor interaction with changing real-time force-axis/vector visualization |

These recordings are qualitative project demonstrations. They document observable hardware/software operation but do not by themselves establish quantitative reconstruction or force-estimation accuracy.
